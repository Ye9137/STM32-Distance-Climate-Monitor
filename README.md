# STM32 距离与温湿度监测

基于 STM32F103C8T6，使用 HC-SR04 测距、DHT11 采集温湿度，并在 I2C OLED 上显示中文数据和状态。

## 功能

- 每 200 ms 测距，每 2.5 秒读取温湿度。
- 显示距离、温度、湿度及正常、错误、超量程或报警状态；启动前 5 秒显示“温湿度校准”。
- 温度严格高于 30℃、湿度严格高于 60%RH、距离严格小于 30 cm，三个条件同时满足时 LED 闪烁。
- LED 每 250 ms 翻转；数据失效或任一条件不满足时关闭报警。

## 默认接线

| 模块 | 信号 | MCU 引脚 |
|---|---|---|
| OLED | SCL / SDA | PC14 / PC15 |
| HC-SR04 | TRIG / ECHO | PA2 / PA3 |
| DHT11 | DATA | PA11 |
| LED | 输出 | PA10 |

OLED 为软件 I2C，7 位地址 `0x3C`。`User/AppConfig.h` 中可修改阈值、采样间隔及 OLED 引脚方案。

原工程的电气要求：HC-SR04 若采用 5V 供电，ECHO 接入 MCU 前需降至 3.3V；DHT11 数据上拉使用 3.3V；LED 串联限流电阻；所有模块共地。当前 OLED 占用 PC14/PC15，不能同时使用这两个引脚连接低速晶振。

## 打开工程

1. 用 Keil µVision 打开 `Project.uvprojx`，安装 STM32F1 设备支持包。
2. 原工程选择 STM32F103C8，配置记录为 Arm Compiler 6.21；按本地工具链情况检查编译器设置。
3. `User/main.c` 为入口，`Hardware/BoardSensors.c` 负责温湿度与系统时基，`Hardware/HCSR04.c` 负责测距。
4. 根据实际调试器重新设置下载选项。编译目录会在本地生成，不随源码发布。
